# Myreader

A PDF reader built for long reading sessions, not a quick-preview tool bolted onto a browser tab.

🔗 **Live demo:** https://v0-myreader.vercel.app/sign-in

## What it does

Myreader is built around actually sitting down and reading a document for an extended stretch - a comfortable reading surface, persistent progress, and an interface that stays out of the way instead of the clutter most PDF viewers ship with. Aimed at the difference between "opening a PDF" and "reading a book-length document."

## Status

Built and deployed via v0/Vercel; the live app is the source of truth. This repository tracks the project on GitHub as a reference point - see the demo link above for the actual product.
